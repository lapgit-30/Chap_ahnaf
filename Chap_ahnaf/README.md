# سامانه آنلاین کافی‌نت و چاپ احناف

سامانه فارسی ثبت سفارش چاپ و کافی‌نت با Next.js App Router، TypeScript، PostgreSQL و Drizzle ORM. فایل سفارش در فضای خصوصی ذخیره می‌شود، بیعانه از زرین‌پال پرداخت می‌شود و ورود مشتری با OTP کاوه‌نگار انجام می‌گیرد.

## پیش‌نیازها

- Node.js 22 و npm
- PostgreSQL 16
- دامنه HTTPS برای محیط عملیاتی
- حساب کاوه‌نگار و الگوی OTP
- درگاه زرین‌پال

## نصب محلی

1. فایل `.env.example` را به `.env` کپی و همه مقادیر را تنظیم کنید.
2. دیتابیس PostgreSQL را بسازید و `DATABASE_URL` را تنظیم کنید.
3. دستورات زیر را اجرا کنید:

```bash
npm ci
npx drizzle-kit push
npx tsx src/db/seed.ts
npm run build
npm start
```

در توسعه می‌توان از `npm run dev` استفاده کرد. فقط در محیط توسعه و با `OTP_DEBUG=true` کد OTP در پاسخ API نمایش داده می‌شود؛ این مقدار در production باید `false` باشد.

## استقرار با Docker و Nginx

1. فایل محیطی بسازید:

```bash
cp .env.example .env
```

2. تمام رمزها، `APP_URL`، مشخصات مدیر، کاوه‌نگار و زرین‌پال را تنظیم کنید.
3. سرویس‌ها را اجرا کنید:

```bash
docker compose up -d --build
```

Compose شامل PostgreSQL، برنامه و Nginx است. برای HTTPS، Nginx میزبان یا سرویس CDN را به پورت 80 متصل و گواهی TLS نصب کنید. حجم‌های `postgres_data` و `uploads` باید در برنامه پشتیبان‌گیری سرور قرار گیرند.

## متغیرهای مهم

- `JWT_SECRET` و `CAPTCHA_SECRET`: دو رشته تصادفی مستقل، حداقل ۳۲ کاراکتر
- `SUPER_ADMIN_*`: مشخصات تنها مدیر کل؛ فقط در اولین seed ساخته می‌شود
- `KAVENEGAR_API_KEY`: کلید API کاوه‌نگار
- `KAVENEGAR_OTP_TEMPLATE`: نام الگوی VerifyLookup که یک token دارد
- `ZARINPAL_MERCHANT_ID`: شناسه پذیرنده زرین‌پال
- `ZARINPAL_SANDBOX`: فقط برای آزمون `true` و در عملیات `false`
- `UPLOAD_DIR`: مسیر دائمی و خصوصی فایل‌های سفارش
- `APP_URL`: آدرس کامل HTTPS بدون اسلش پایانی، برای callback پرداخت

## راهنمای مشتری

1. از منوی سایت روی «ثبت‌نام» بزنید، مشخصات و کپچا را وارد و کد پیامکی را تأیید کنید.
2. پس از ورود، صفحه اصلی نمایش داده می‌شود؛ برای ثبت سفارش به «خدمات» یا «ثبت سفارش» بروید.
3. دسته و خدمت را انتخاب کنید. فرم فقط گزینه‌های همان خدمت را نمایش می‌دهد.
4. تعداد، توضیحات و در صورت نیاز فایل را ثبت کنید. فرمت‌های مجاز PDF، JPG، PNG، DOC، DOCX و ZIP است؛ هر فایل حداکثر ۲۰ و مجموع فایل‌ها حداکثر ۵۰ مگابایت است.
5. کد رهگیری را نگه دارید. از صفحه «پیگیری سفارش» وضعیت، مبلغ و زمان تحویل را ببینید.
6. پس از تعیین بیعانه توسط مدیر، در صفحه رهگیری وارد حساب شوید و «پرداخت آنلاین بیعانه» را بزنید.
7. باقی مبلغ هنگام تحویل حضوری دریافت می‌شود.

## راهنمای مدیر کل

1. مسیر مدیریت در منوی عمومی نیست؛ مستقیم به `/admin` بروید.
2. با `SUPER_ADMIN_USERNAME` و `SUPER_ADMIN_PASSWORD` وارد شوید.
3. در «سفارشات»، سفارش را باز کنید؛ مبلغ کل، بیعانه، تاریخ تحویل و وضعیت را تعیین و ذخیره کنید.
4. فایل مشتری فقط از دکمه دانلود authenticated داخل جزئیات سفارش قابل دریافت است.
5. در «پرداخت‌ها»، تراکنش‌های pending و موفق و شماره مرجع را ببینید.
6. در «خدمات» گزینه‌ها را به شکل JSON وارد کنید؛ نمونه: `{"سایز":["A4","A3"],"نوع چاپ":["رنگی","سیاه‌وسفید"]}`.
7. در «دسته‌بندی‌ها» گروه‌های چاپ و کافی‌نت را ایجاد یا غیرفعال کنید.
8. در «کاربران» با کلیک روی وضعیت، دسترسی مشتری را فعال یا مسدود کنید.
9. در «تنظیمات» اطلاعات تماس و درصدهای پیش‌فرض را نگهداری کنید.

## نگهداری و پشتیبان‌گیری

```bash
# پشتیبان دیتابیس
pg_dump "$DATABASE_URL" > ahnaf-$(date +%F).sql

# بازیابی
psql "$DATABASE_URL" < ahnaf-YYYY-MM-DD.sql
```

علاوه بر دیتابیس، مسیر `UPLOAD_DIR` را روزانه پشتیبان بگیرید. دسترسی این پوشه نباید از Nginx یا وب‌سرور عمومی ارائه شود.

## بررسی سلامت

`GET /api/health` اتصال برنامه و PostgreSQL را بررسی می‌کند. پاسخ HTTP 200 به معنی سلامت سرویس است.
